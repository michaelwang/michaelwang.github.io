# 銀行の貯金利益低いときに、資本は高い利益が追求する性質があり、高い利益分野に流れる、これから、新会社はたくさんの資本が流れていき、たくさんの新会社は生まれ、多くの職も生まれることがあります。

# 現在はアメリカの銀行の利益が低いです、資本は新会社に投資すると、リスクがあり、一時間後に新会社の業務が失敗し、投資の資本が失われることがあります、ただし、この資本が銀行に預けられていれば、一時間後に高い利益が得られます、なぜ資本が新会社に投資されるのでしょうか。

# その上、現在はソフトウェアの開発のエンジニアが仕事を探すのは難しいですね。この文の作者はソフトエアエンジニアに次のようなアドヴァイスをしています。
